# Quellen für TU-spezifische Regeln

Dieses Verzeichnis dokumentiert die fachliche Grundlage für TU-spezifische
Terminologie-, Stil- und Whitelist-Regeln.

## Schutz von Quellen

Zugriffsgeschützte, interne oder hinsichtlich ihrer Weitergabe ungeklärte
Originaldokumente dürfen nicht in dieses GitHub-Repository eingecheckt werden.
Dies gilt auch dann, wenn das Repository privat ist.

Solche Originalquellen werden separat auf einem für sie zugelassenen Speicherort
archiviert und versioniert. Dieses Repository enthält nur frei teilbare
Metadaten, Quellen-IDs und abgeleitete technische Regeln.

Öffentliche Originalquellen dürfen nur nach bewusster Prüfung der
Speicher- und Weitergaberechte in diesem Repository archiviert werden.
In der Regel genügt auch für öffentliche Quellen ein URL-Verweis mit
Abrufdatum und Quellen-ID.

## Quellen-IDs

Jede technische TU-Regel muss auf mindestens eine nachvollziehbare Quellen-ID
verweisen. Die Quellen-ID verweist auf die zugehörige Quellenverwaltung im
privaten Quellenbestand.

Beispiel:

```yaml
id: tu-de-gender-star-preferred
profile: tu-de
category: inclusive_language
authority: recommended
source_ids:
  - tu-gender-language-2021
```
